# Charlotte NC House Price Prediction

An end-to-end machine learning project that predicts residential
property prices in Charlotte, North Carolina.

## Project Goals

- Collect public property data
- Clean and validate the data
- Perform exploratory data analysis
- Engineer useful features
- Train multiple machine learning models
- Evaluate model performance
- Select the best model
- Build a Flask prediction API
- Build a web interface
- Add automated tests
- Containerize the application with Docker
- Deploy the application to AWS

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- Flask
- Pytest
- Docker
- Git
- GitHub
- AWS

## Data Sources

Primary data source:

- Mecklenburg County GIS / public property data

Additional market-level data may be incorporated from public housing
market datasets where appropriate.
